# B5: Remove ChunkRow imports from test_health.py and update CLAUDE.md

**Avoid:** Do not change the health.py script itself unless it directly imports ChunkRow (check first). The test file test_health.py is the primary target -- it imports ChunkRow from storage and uses it to seed test data via insert_chunk. These must be converted to use DataPointRow + insert_data_point instead. Do not remove health.py functions -- only update tests.

## Steps

### Step 1: Update test_health.py imports

Current imports (approximate):
```python
from storage import (
    ChunkRow,
    insert_chunk,
    ...
)
```

Replace with:
```python
from storage import (
    DataPointRow,
    insert_data_point,
    ...
)
```

### Step 2: Convert ChunkRow test data to DataPointRow

Find all places in test_health.py where `ChunkRow(...)` is used to create test data. Replace with equivalent `DataPointRow(...)` calls.

ChunkRow fields map to DataPointRow as follows:
| ChunkRow field | DataPointRow field |
|---|---|
| `content` | `content` |
| `source_file` | `source_type` (use the source_file value as source_type) |
| `source_type` | `source_type` |
| `scope` | `scope` |
| `section` | (dropped -- not in DataPointRow) |
| `entry_type` | `entry_type` |
| `salience` | `salience` |
| `access_count` | `access_count` |

DataPointRow requires `type` field. Set `type="memory"` for all converted test data.

Replace `insert_chunk(db, ChunkRow(...))` with `insert_data_point(db, DataPointRow(...))`.

### Step 3: Verify health.py itself

Check if `health.py` imports ChunkRow or insert_chunk directly:
```bash
grep -n "ChunkRow\|insert_chunk" scripts/health.py
```

If it does, update those imports and usages too. If not, only the test file needs changes.
