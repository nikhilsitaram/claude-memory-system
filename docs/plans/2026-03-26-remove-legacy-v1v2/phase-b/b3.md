# B3: Delete token_usage.py, markdown templates, test_migration.py, and test_token_usage.py

**Avoid:** Do not delete `templates/settings.json` or `templates/web/` -- those are still used by install.py. Only delete the three markdown template files and the two obsolete scripts/tests.

## Steps

### Step 1: Delete scripts/token_usage.py

```bash
git rm scripts/token_usage.py
```

This file was an approximation of token usage across memory tiers using short-term settings that no longer exist.

### Step 2: Delete markdown template files

```bash
git rm templates/daily-template.md
git rm templates/global-long-term-memory.md
git rm templates/project-long-term-memory.md
```

These templates were used by the markdown-based memory system. The v3 system uses DB-only storage.

### Step 3: Delete test files for removed code

```bash
git rm tests/test_migration.py
git rm tests/test_token_usage.py
```

`test_migration.py` tests `migrate_markdown_to_db` and `_archive_markdown_files` which were removed in A1.
`test_token_usage.py` tests `token_usage.py` which was deleted in Step 1.

### Step 4: Verify no remaining imports

Check that no remaining file imports from the deleted modules:
```bash
grep -rn "token_usage" scripts/ tests/
grep -rn "test_migration" tests/
grep -rn "daily-template" scripts/
```

If any remaining references are found, update them.

### Step 5: Run full test suite

```bash
python3 -m pytest tests/ -q
```

All tests must pass. The deleted test files should not be discovered.
