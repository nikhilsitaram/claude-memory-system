### Step 2: Refactor create_database()

Current `create_database()` (line 271) imports `SCHEMA_DDL`, `_migrate_v2_to_v3`, `migrate_markdown_to_db` from storage, creates a v2 DB, runs markdown migration, then migrates to v3. Replace with a simple `ensure_db()` call.

Replace the entire function body:
```python
def create_database(script_dir: Path) -> None:
    """Create or update memory.db with v3 schema.

    Non-fatal -- prints warning on failure.
    """
    try:
        scripts_path = script_dir / "scripts"
        if str(scripts_path) not in sys.path:
            sys.path.insert(0, str(scripts_path))

        from storage import close_db, ensure_db

        conn = ensure_db()
        close_db(conn)
        print("Memory database ready (v3 schema)")
    except Exception as e:
        print(f"Warning: Could not create memory database: {e}")
        print("  Memory context will be empty until the database is created.")
```

This removes all imports of `migrate_markdown_to_db`, `_migrate_v2_to_v3`, and `SCHEMA_DDL` from the function.
