# D1: Create HTTP server with API endpoints

**Avoid:** Do not use Flask, FastAPI, or any external web framework -- use Python's built-in `http.server` module. The design doc explicitly says "no build step, no npm, no React." Do not bind to `0.0.0.0` -- bind to `127.0.0.1` only (security: single-user localhost tool). Do not use CORS headers (same-origin only). Do not create a connection pool -- open a single DB connection at startup and reuse it. Do not serve the HTML file in this task (that's D3).
