# D3: Create single-page HTML frontend with vis.js

**Avoid:** Do not use npm, React, Vue, or any build step -- the design doc specifies "single HTML file with embedded CSS + vanilla JS + vis.js." Do not fetch vis.js from a local file -- use the CDN link (`https://unpkg.com/vis-network/standalone/umd/vis-network.min.js`). Do not hardcode the CSRF token in the HTML source -- the server injects it at serve time via string replacement. Do not make the page depend on external CSS frameworks.

## Steps

### Step 1: Create templates/web/index.html

This is a self-contained HTML file with:

- Inline CSS for layout and styling
- vis.js loaded from CDN
- Navigation tabs: Dashboard, Browse, Search, Graph, (Detail view is a modal)
- CSRF token placeholder: `{{CSRF_TOKEN}}` replaced by server

Key sections:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="utf-8">
    <title>Claude Memory System</title>
    <script src="https://unpkg.com/vis-network/standalone/umd/vis-network.min.js"></script>
    <style>
        /* Inline CSS: sidebar nav, main content area, cards, tables, graph container */
    </style>
</head>
<body>
    <nav><!-- Dashboard | Browse | Search | Graph --></nav>
    <main>
        <section id="dashboard"><!-- Stats cards, salience histogram, recent activity --></section>
        <section id="browse"><!-- Scope/type/salience filters, paginated table --></section>
        <section id="search"><!-- Search input, results list --></section>
        <section id="graph"><!-- vis.js network container --></section>
    </main>
    <div id="detail-modal"><!-- Data point detail with edges, provenance, edit/delete --></div>
    <script>
        const CSRF_TOKEN = "{{CSRF_TOKEN}}";
        // Vanilla JS: fetch API endpoints, render views, vis.js graph setup
    </script>
</body>
</html>
```

### Step 2: Implement Dashboard view

JS fetches `/api/stats`, renders:
- Total memories, entities, session contexts count
- Salience distribution histogram (simple bar chart with CSS)
- 5 most recent data_points

### Step 3: Implement Browse view

JS fetches `/api/data_points` with filter params. Renders a table with columns: Content (truncated), Scope, Type, Salience, Date. Click to open detail modal.

### Step 4: Implement Search view

Text input, JS fetches `/api/search?q=...`. Results list with score, content, scope. Click to open detail.

### Step 5: Implement Graph view

JS fetches `/api/graph?scope=...`. Builds vis.js network:
- Nodes: data_points (colored by type: memory=blue, entity=green, session_context=orange, profile=gold)
- Edges: labeled by type, colored by relationship category
- Click node to open detail modal

### Step 6: Implement Detail modal with edit/delete

Shows full data_point content, all edges, provenance chain. Edit button opens inline form. Delete button with confirmation.

### Step 7: Update web_app.py to serve HTML with token injection

```python
def _serve_html(self):
    html_path = Path(__file__).parent.parent / "templates" / "web" / "index.html"
    content = html_path.read_text(encoding="utf-8")
    content = content.replace("{{CSRF_TOKEN}}", _csrf_token)
    self.send_response(200)
    self.send_header("Content-Type", "text/html; charset=utf-8")
    self.end_headers()
    self.wfile.write(content.encode())
```
