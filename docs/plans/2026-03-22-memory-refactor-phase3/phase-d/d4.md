# D4: Add web_app.py to install.py

**Avoid:** Do not make the web app start automatically at install -- it's a manual `python3 ~/.claude/scripts/web_app.py` command. Do not add web_app.py as a hook -- it's not triggered by any Claude Code event. Do not forget to copy the `templates/web/` directory.

## Steps

### Step 1: Add web_app.py to link_scripts

In `install.py`, add `"web_app.py"` to the `scripts_to_link` list in `link_scripts()`.

### Step 2: Copy templates/web/ directory

In `copy_templates()`, add:

```python
# Copy web frontend templates
web_templates_src = script_dir / "templates" / "web"
web_templates_dest = memory_dir / "templates" / "web"
if web_templates_src.exists():
    web_templates_dest.mkdir(parents=True, exist_ok=True)
    for f in web_templates_src.iterdir():
        shutil.copy2(f, web_templates_dest / f.name)
    print("Copied web frontend templates")
```

### Step 3: Update success message

Add to `print_success_message()`:

```python
print("  Web UI:     python3 ~/.claude/scripts/web_app.py")
print("              Opens http://localhost:8742")
```

### Step 4: Verify

```bash
python3 -c "import ast; tree = ast.parse(open('install.py').read()); print('OK')"
```

Run install and verify web_app.py is symlinked:

```bash
python3 install.py
ls -la ~/.claude/scripts/web_app.py
```
