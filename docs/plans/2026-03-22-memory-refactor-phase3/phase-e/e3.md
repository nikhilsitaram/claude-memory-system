**Avoid:** Do not use a hardcoded absolute path for the memory_server.py command -- use the `~/.claude/scripts/` path pattern that install.py already uses for hooks. Do not remove existing mcpServers entries -- merge the memory server in alongside any existing ones. Do not forget to add memory_server.py to `link_scripts()`.

### Step 2: Implement merge_mcp_servers in install.py

```python
def merge_mcp_servers(settings, python_cmd):
    """Add memory MCP server configuration to settings."""
    home = str(Path.home())
    scripts_dir = f"{home}/.claude/scripts"

    if "mcpServers" not in settings:
        settings["mcpServers"] = {}

    settings["mcpServers"]["memory"] = {
        "command": python_cmd,
        "args": [f"{scripts_dir}/memory_server.py"],
        "env": {},
    }

    return settings
```

### Step 3: Wire into main() and add to link_scripts

In `main()`, after `merge_hooks`:
```python
settings = merge_mcp_servers(settings, python_cmd)
```

In `link_scripts()`, add `"memory_server.py"` to `scripts_to_link`.
