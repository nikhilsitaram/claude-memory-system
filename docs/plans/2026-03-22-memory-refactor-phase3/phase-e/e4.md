# E4: Deprecate /recall and /remember skills

**Avoid:** Do not delete the skill directories -- keep them for backward compatibility during the transition. Users who type `/recall` should get a helpful message pointing to the MCP tool, not an error. Do not remove the skills from `link_skills()` in install.py -- they still need to be symlinked to show the deprecation message.

## Steps

### Step 1: Update skills/recall/SKILL.md

Read the existing SKILL.md, then replace the content with a deprecation notice:

```markdown
---
name: recall
description: "[DEPRECATED] Search memory - use search_memories MCP tool instead"
---

# /recall - DEPRECATED

This skill has been replaced by the `search_memories` MCP tool, which Claude calls automatically when relevant.

**Migration:** Instead of typing `/recall`, Claude now proactively searches memories during conversation using the `search_memories` tool. You don't need to do anything -- relevant memories surface automatically.

**Manual search:** If you want to explicitly search, ask Claude: "Search my memories for [topic]" and Claude will use the `search_memories` tool.
```

### Step 2: Update skills/remember/SKILL.md

```markdown
---
name: remember
description: "[DEPRECATED] Save to memory - use write_memory MCP tool instead"
---

# /remember - DEPRECATED

This skill has been replaced by the `write_memory` MCP tool, which Claude calls automatically when it detects important facts.

**Migration:** Instead of typing `/remember`, Claude now proactively writes memories during conversation using the `write_memory` tool. Important facts, decisions, and learnings are captured automatically.

**Manual save:** If you want to explicitly save something, tell Claude: "Remember that [fact]" and Claude will use the `write_memory` tool.
```

### Step 3: Update install.py success message

In `print_success_message()`, replace:
```
  /remember   - Save notes to daily log
  /recall     - Search historical memory
```
with:
```
  /synthesize - Process transcripts & update memory
  /settings   - View/modify memory settings & token usage
  /projects   - Manage projects (move, merge orphans, cleanup)

MCP tools (Claude calls these automatically):
  search_memories  - Semantic memory search
  write_memory     - Save facts to knowledge base
  delete_memory    - Remove outdated memories
  traverse_graph   - Navigate knowledge graph
```

### Step 4: Verify

```bash
python3 -c "content = open('skills/recall/SKILL.md').read(); assert 'deprecated' in content.lower() or 'DEPRECATED' in content; print('OK')"
python3 -c "content = open('skills/remember/SKILL.md').read(); assert 'deprecated' in content.lower() or 'DEPRECATED' in content; print('OK')"
```
