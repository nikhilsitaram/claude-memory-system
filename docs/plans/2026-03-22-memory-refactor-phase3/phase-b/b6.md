# B6: Add pip dependency for mcp SDK

**Avoid:** Do not add `mcp` as a hard dependency that blocks installation -- put it in an optional extras group (e.g., `[mcp]`) or handle ImportError gracefully in memory_server.py. The memory system must remain functional without the MCP server (graceful degradation per the design doc). Do not pin to a specific mcp SDK micro-version -- use a compatible range (e.g., `>=1.0.0,<2.0.0`).

## Steps

### Step 1: Check current pyproject.toml structure

Read `pyproject.toml` to understand existing dependency format.

### Step 2: Add mcp SDK to optional dependencies

```toml
[project.optional-dependencies]
mcp = ["mcp>=1.0.0,<2.0.0"]
```

Or if the project uses a different dependency management approach, adapt accordingly.

### Step 3: Update memory_server.py import guard

Ensure `memory_server.py` has a try/except around the mcp import:

```python
try:
    from mcp.server import Server
    from mcp.server.stdio import stdio_server
    from mcp.types import Tool, TextContent
    HAS_MCP = True
except ImportError:
    HAS_MCP = False
```

And in `main()`:
```python
if not HAS_MCP:
    print("Error: mcp SDK not installed. Run: pip install mcp", file=sys.stderr)
    sys.exit(1)
```

### Step 4: Verify installation

```bash
pip install -e ".[mcp]"
python3 -c "import mcp; print('mcp SDK available')"
```
