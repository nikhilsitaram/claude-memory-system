# C3: Rewrite apply pipeline for DB-only writes

**Avoid:** Do not call any of: `build_dailies_from_project_blocks`, `write_daily_files`, `append_to_ltm`, `mark_routed_entries`, or any other function that writes to markdown files. The entire point of this task is that apply writes ONLY to the database. Do not reuse `apply_memory_ops` (the Phase 2 version) -- create `apply_memory_ops_v3` as a clean implementation. Do not forget to generate embeddings for ADD and UPDATE operations. Do not set a default salience of 1.0 for ADD -- use the LLM-assigned value, falling back to 0.5 if not provided.

### Step 2: Implement apply_memory_ops_v3

```python
def apply_memory_ops_v3(conn, ops):
    results = []
    for op in ops:
        if op.action == "ADD":
            result = _apply_add_v3(conn, op)
        elif op.action == "UPDATE":
            result = _apply_update_v3(conn, op)
        elif op.action == "DELETE":
            result = _apply_delete_v3(conn, op)
        elif op.action == "NOOP":
            result = _apply_noop_v3(conn, op)
        else:
            result = {"action": op.action, "status": "unknown_action"}
        results.append(result)
    conn.commit()
    return results
```

Each `_apply_*_v3` helper operates on `data_points` table only, creates edges for provenance, and generates embeddings.
