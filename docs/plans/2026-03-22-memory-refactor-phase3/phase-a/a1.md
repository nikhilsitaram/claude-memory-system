# A1: Define v3 schema DDL and DataPointRow dataclass

**Avoid:** Do not drop the old chunks/nodes tables in this task -- that happens in A3 (migration). The v3 DDL uses `CREATE TABLE IF NOT EXISTS` so it coexists with v2 tables during migration. Do not change SCHEMA_VERSION yet in `ensure_db()` -- A3 will set version=3 after migration logic is in place. The reason: if we bump version before migration code exists, users who run `ensure_db()` will get version=3 without the actual data migration.

## Steps

class TestV3Schema:

### Step 2: Define DataPointRow dataclass in storage.py

Add after the existing `EdgeRow` dataclass:

```python
@dataclass
class DataPointRow:
    """Represents a row in the data_points table (v3 schema)."""
    type: str                              # 'memory', 'entity', 'session_context', 'profile'
    content: Optional[str] = None
    scope: Optional[str] = None
    name: Optional[str] = None             # for entities: "JWT", "gRPC". NULL for memories.
    entry_type: Optional[str] = None       # implement, design, gotcha, tip, etc.
    source_type: Optional[str] = None      # 'synthesis', 'manual', 'migration', 'session_end'
    source_sessions: Optional[str] = None  # JSON array of session IDs
    created_at: Optional[str] = None
    salience: float = 1.0
    access_count: int = 0
    last_accessed: Optional[str] = None
    evidence_count: int = 1
    consolidated: int = 0
    content_hash: Optional[str] = None
    simhash: Optional[int] = None
    entities: Optional[str] = None         # JSON: extracted entities (for memories)
    properties: Optional[str] = None       # JSON: flexible extra fields
    id: Optional[str] = None
```

Add `DataPointRow` to `__all__`.

### Step 3: Define SCHEMA_V3_DDL constant

Add after the existing `VEC_CHUNKS_DDL` constant:

```python
SCHEMA_V3_DDL = """\
-- Unified data_points table (replaces chunks + nodes)
CREATE TABLE IF NOT EXISTS data_points (
    id TEXT PRIMARY KEY,
    type TEXT NOT NULL,
    name TEXT,
    content TEXT,
    scope TEXT,
    entry_type TEXT,
    source_type TEXT,
    source_sessions TEXT,
    created_at TEXT NOT NULL,
    salience REAL DEFAULT 1.0,
    access_count INTEGER DEFAULT 0,
    last_accessed TEXT,
    evidence_count INTEGER DEFAULT 1,
    consolidated INTEGER DEFAULT 0,
    content_hash TEXT,
    simhash INTEGER,
    entities TEXT,
    properties TEXT
);

-- Add reason column to edges (v3 addition, safe if column exists)
-- Note: ALTER TABLE is handled in migration code, not here.
-- This DDL is for fresh installs only.

-- Vector layer for data_points
CREATE VIRTUAL TABLE IF NOT EXISTS vec_data USING vec0(
    embedding float[384],
    +data_point_id TEXT,
    +type TEXT
);

-- Indexes for data_points
CREATE INDEX IF NOT EXISTS idx_dp_type ON data_points(type);
CREATE INDEX IF NOT EXISTS idx_dp_scope ON data_points(scope);
CREATE INDEX IF NOT EXISTS idx_dp_salience ON data_points(salience);
CREATE INDEX IF NOT EXISTS idx_dp_created ON data_points(created_at);
CREATE INDEX IF NOT EXISTS idx_dp_hash ON data_points(content_hash);
CREATE INDEX IF NOT EXISTS idx_dp_simhash ON data_points(simhash);
"""

VEC_DATA_DDL = """\
CREATE VIRTUAL TABLE IF NOT EXISTS vec_data USING vec0(
    embedding float[384],
    +data_point_id TEXT,
    +type TEXT
);
"""
```

Add `SCHEMA_V3_DDL` and `VEC_DATA_DDL` to `__all__`.

Note: The `reason` column on edges is added via ALTER TABLE in the migration function (A3), not in the DDL. This is because ALTER TABLE IF NOT EXISTS isn't supported in SQLite, so it must be version-gated.
