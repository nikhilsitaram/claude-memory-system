### Step 2: Implement _migrate_profiles in storage.py

Parse the global LTM file for profile sections (About Me, Current Projects, Technical Environment, Patterns & Preferences). For each section with content, create a data_point:

```python
PROFILE_SECTIONS = {"About Me", "Current Projects", "Technical Environment", "Patterns & Preferences"}

def _migrate_profiles(conn, ltm_path):
    if not ltm_path.exists():
        return
    content = ltm_path.read_text(encoding="utf-8")
    # Parse sections
    current_header = None
    current_lines = []
    for line in content.split("\n"):
        if line.startswith("## "):
            if current_header in PROFILE_SECTIONS and current_lines:
                _insert_profile_section(conn, current_header, current_lines)
            current_header = line[3:].strip()
            current_lines = []
        elif current_header:
            current_lines.append(line)
    # Handle last section
    if current_header in PROFILE_SECTIONS and current_lines:
        _insert_profile_section(conn, current_header, current_lines)
```

Use content_hash for idempotency -- skip if a profile data_point with the same hash exists.
