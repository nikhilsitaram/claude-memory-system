### Step 2: Add `ensure_vec_table()`

Append to `scripts/embeddings.py`:

def ensure_vec_table(conn: sqlite3.Connection) -> bool:
    """Create the vec_chunks virtual table if sqlite-vec is available.

    Args:
        conn: Open SQLite connection.

    Returns:
        True if vec_chunks table is ready, False if sqlite-vec is not available.
    """
    if not HAS_SQLITE_VEC:
        return False
    try:
        sqlite_vec.load(conn)
        conn.executescript(VEC_CHUNKS_DDL)
        conn.commit()
        return True
    except Exception:
        return False
```

### Step 3: Add `embed_text()` and `embed_batch()`

def embed_text(text: str) -> list[float]:
    """Embed a single text string into a 384-dim vector.

    Args:
        text: Input text to embed.

    Returns:
        List of 384 floats, or empty list if fastembed is not available.
    """
    model = _get_model()
    if model is None:
        return []
    results = list(model.embed([text]))
    if not results:
        return []
    return [float(x) for x in results[0]]


def embed_batch(texts: list[str]) -> list[list[float]]:
    """Embed multiple texts into 384-dim vectors.

    Args:
        texts: List of input texts.

    Returns:
        List of vectors (each 384 floats), or empty list if fastembed
        is not available or input is empty.
    """
    if not texts:
        return []
    model = _get_model()
    if model is None:
        return []
    return [[float(x) for x in vec] for vec in model.embed(texts)]
```

### Step 4: Add `_serialize_vector()` helper for sqlite-vec

sqlite-vec expects vectors as raw bytes (packed float32). Add this helper:

```python
def _serialize_vector(vec: list[float]) -> bytes:
    """Serialize a float vector to bytes for sqlite-vec storage."""
    return struct.pack(f"{len(vec)}f", *vec)
```
