# A3: Index and delete operations for vec_chunks

**Avoid:** Do not pass `Chunk` dataclass instances (from `chunking.py`) into these functions -- accept chunk IDs (strings) and query the DB internally. This avoids type boundary issues between `Chunk` (chunking.py) and `ChunkRow` (storage.py). Do not forget to call `conn.commit()` after batch inserts -- sqlite-vec INSERT is not autocommit. Do not embed chunks that already exist in vec_chunks with the same content_hash -- check by JOINing `vec_chunks.chunk_id` to `chunks.id` and comparing `chunks.content_hash`.

**Avoid:** Do not use `INSERT OR REPLACE` for vec_chunks -- sqlite-vec virtual tables may not support all conflict resolution modes. Instead, check existence first with a SELECT, then INSERT only new rows.

### Step 1: Replace the `index_chunks` stub

In `scripts/embeddings.py`, replace the `index_chunks` stub with the full implementation:

```python
def index_chunks(conn: sqlite3.Connection, chunk_ids: list[str]) -> None:
    """Embed and index chunks by their IDs.

    Queries the chunks table for the given IDs, embeds their content,
    and inserts vectors into vec_chunks. Skips chunks that already
    exist in vec_chunks with the same content_hash.

    Args:
        conn: Open SQLite connection with vec_chunks table created.
        chunk_ids: List of chunk IDs to embed and index.
    """
    if not chunk_ids or not HAS_FASTEMBED:
        return

    placeholders = ",".join("?" * len(chunk_ids))
    rows = conn.execute(
        f"SELECT {_CHUNK_COLUMNS} FROM chunks WHERE id IN ({placeholders})",
        chunk_ids,
    ).fetchall()

    if not rows:
        return

    chunks = [_row_to_chunk(r) for r in rows]

    # Build a map of chunk_id -> content_hash for chunks already in vec_chunks.
    # Skip re-embedding only if the chunk_id exists AND the content_hash matches
    # (per design doc Key Decision #4).
    existing_hashes = {}
    try:
        existing_rows = conn.execute(
            f"SELECT vc.chunk_id, c.content_hash FROM vec_chunks vc "
            f"JOIN chunks c ON vc.chunk_id = c.id "
            f"WHERE vc.chunk_id IN ({placeholders})",
            chunk_ids,
        ).fetchall()
        existing_hashes = {r[0]: r[1] for r in existing_rows}
    except Exception:
        pass

    to_embed = [
        c for c in chunks
        if c.id not in existing_hashes or existing_hashes[c.id] != c.content_hash
    ]
    if not to_embed:
        return

    texts = [c.content for c in to_embed]
    vectors = embed_batch(texts)

    if len(vectors) != len(to_embed):
        return

    for chunk, vec in zip(to_embed, vectors):
        conn.execute(
            "INSERT INTO vec_chunks (embedding, chunk_id, source_type) VALUES (?, ?, ?)",
            (_serialize_vector(vec), chunk.id, chunk.source_type),
        )
    conn.commit()
```

### Step 2: Replace the `index_chunks_by_source` stub

```python
def index_chunks_by_source(conn: sqlite3.Connection, source_files: list[str]) -> None:
    """Embed and index all chunks from the given source files.

    Convenience wrapper: queries chunks table by source_file,
    then calls index_chunks with the resulting IDs.

    Args:
        conn: Open SQLite connection with vec_chunks table created.
        source_files: List of source file paths to index.
    """
    if not source_files or not HAS_FASTEMBED:
        return

    all_ids = []
    for sf in source_files:
        rows = conn.execute(
            "SELECT id FROM chunks WHERE source_file = ?", (sf,)
        ).fetchall()
        all_ids.extend(r[0] for r in rows)

    if all_ids:
        index_chunks(conn, all_ids)
```

### Step 3: Replace the `delete_vec_chunks` stub

```python
def delete_vec_chunks(conn: sqlite3.Connection, chunk_ids: list[str]) -> None:
    """Remove vectors for the given chunk IDs from vec_chunks.

    Args:
        conn: Open SQLite connection.
        chunk_ids: List of chunk IDs whose vectors should be deleted.
    """
    if not chunk_ids:
        return

    for cid in chunk_ids:
        conn.execute(
            "DELETE FROM vec_chunks WHERE chunk_id = ?", (cid,)
        )
    conn.commit()
```
