# A5: Reindex functions and synthesis.py integration

**Avoid:** Do not call `reindex_all()` with a connection that hasn't had `ensure_vec_table()` called -- the function should call `ensure_vec_table()` internally to be self-contained. Do not let exceptions from the reindex step propagate up through `run_post_processing()` -- wrap in try/except (non-critical step, per design doc). Do not import `embeddings` at module level in `synthesis.py` -- import inside the function to avoid circular imports and to keep synthesis.py working even if fastembed/sqlite-vec aren't installed.

**Avoid:** Do not use `storage.ensure_db()` inside reindex functions -- the caller provides the connection. But `_reindex_after_synthesis()` in synthesis.py needs to open its own connection since it is called from `run_post_processing()` which does not pass one.

### Step 1: Replace the `reindex_changed_files` stub

```python
def reindex_changed_files(conn: sqlite3.Connection, changed_files: list[str]) -> None:
    """Re-index vectors for chunks from the given source files.

    Deletes existing vectors for all chunks in those files, then
    re-embeds and inserts fresh vectors.

    Args:
        conn: Open SQLite connection with vec_chunks table created.
        changed_files: List of source file paths whose chunks changed.
    """
    if not changed_files or not HAS_FASTEMBED:
        return

    for sf in changed_files:
        chunk_ids = [
            r[0] for r in conn.execute(
                "SELECT id FROM chunks WHERE source_file = ?", (sf,)
            ).fetchall()
        ]
        if chunk_ids:
            delete_vec_chunks(conn, chunk_ids)

    index_chunks_by_source(conn, changed_files)
```

### Step 2: Replace the `reindex_all` stub

```python
def reindex_all(conn: sqlite3.Connection) -> None:
    """Full re-index of all chunks in the database.

    Creates the vec_chunks table if needed, clears all existing vectors,
    then embeds and indexes every chunk. This is the only function called
    by the Phase 1 synthesis integration.

    Args:
        conn: Open SQLite connection.
    """
    if not HAS_FASTEMBED:
        return

    if not ensure_vec_table(conn):
        return

    try:
        conn.execute("DELETE FROM vec_chunks")
        conn.commit()
    except Exception:
        pass

    all_ids = [
        r[0] for r in conn.execute("SELECT id FROM chunks").fetchall()
    ]

    if all_ids:
        index_chunks(conn, all_ids)
```

### Step 3: Add `_reindex_after_synthesis()` to synthesis.py

In `scripts/synthesis.py`, add a new function and call it from `run_post_processing()`.

First, add the function after `run_decay()` (around line 778):

```python
def _reindex_after_synthesis() -> None:
    """Re-index all chunk vectors after synthesis completes.

    Opens its own DB connection, calls reindex_all(), then closes.
    Non-critical: failures are silently ignored.
    """
    try:
        from embeddings import reindex_all
        from storage import get_db, close_db

        conn = get_db()
        try:
            reindex_all(conn)
        finally:
            close_db(conn)
    except Exception:
        pass
```

Then, in `run_post_processing()`, add the reindex call after `run_decay()` and before the timestamp update. The current code at the end of `run_post_processing()` looks like:

```python
    run_mark_routed()
    run_validate_ltm()
    run_decay()

    # Update timestamp
    ts_file = get_memory_dir() / ".last-synthesis"
```

Change it to:

```python
    run_mark_routed()
    run_validate_ltm()
    run_decay()

    try:
        _reindex_after_synthesis()
    except Exception:
        pass

    # Update timestamp
    ts_file = get_memory_dir() / ".last-synthesis"
```

Also add `_reindex_after_synthesis` to the `__all__` list in synthesis.py (for testability).
