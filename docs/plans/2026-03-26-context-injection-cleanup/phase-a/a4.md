# A4: Pre-retrieval enhancement for synthesis prompt

**Avoid:** Do not modify `retrieve_existing_memories()` or its vector-search logic. This task adds a *separate* scope-filtered memory injection in `_run_synthesis_v3`, not a change to the vector retrieval path. The design doc says "belt-and-suspenders" -- vector retrieval (existing) covers semantic similarity; this new injection covers the top memories by salience for the target scope so the LLM sees what already exists.

**Avoid:** Do not add the scope memories to the prompt built by `_build_synthesis_prompt` or `_build_preextracted_prompt` in `load_memory.py`. The injection happens in `synthesis_cron.py`'s `_run_synthesis_v3` *after* the prompt is read from file and *before* it's sent to `claude -p`.

### Step 2: Implement scope memory injection in scripts/synthesis_cron.py

Add a new function `_inject_scope_memories`:

```python
def _inject_scope_memories(conn, prompt_text: str, scope: str, limit: int = 10) -> str:
    """Inject top existing memories for the scope into the synthesis prompt.

    Adds an 'Existing Memories for scope' section before the '## Transcripts'
    marker. This gives the LLM context to choose UPDATE over ADD for semantic
    duplicates that SimHash might miss.

    Args:
        conn: Open SQLite connection.
        prompt_text: The synthesis prompt text.
        scope: Project scope to query memories for.
        limit: Maximum number of memories to inject.

    Returns:
        Modified prompt text with injected memories section.
    """
    rows = conn.execute(
        "SELECT id, content FROM data_points "
        "WHERE type='memory' AND scope=? AND salience > 0 "
        "ORDER BY salience DESC LIMIT ?",
        (scope, limit),
    ).fetchall()

    if not rows:
        return prompt_text

    memory_lines = [f"[{row[0]}] {row[1]}" for row in rows if row[1]]
    if not memory_lines:
        return prompt_text

    section = (
        f"\n## Existing Memories for scope: {scope}\n"
        "Reference these by [id] when choosing UPDATE vs ADD.\n\n"
        + "\n".join(memory_lines)
        + "\n"
    )

    # Insert before ## Transcripts if present, otherwise append before end
    if "## Transcripts" in prompt_text:
        return prompt_text.replace("## Transcripts", section + "\n## Transcripts", 1)
    return prompt_text + section
```

Then in `_run_synthesis_v3`, after reading the prompt file and applying v3 instruction replacement (around line 320-338), add:

```python
# Inject top existing memories for the target scope (pre-retrieval enhancement)
# Extract scope from prompt text (pattern: 'for project "NAME"')
import re
scope_match = re.search(r'for project "([^"]+)"', prompt_text)
if scope_match:
    prompt_scope = scope_match.group(1)
    prompt_text = _inject_scope_memories(conn, prompt_text, prompt_scope)
```

Add `_inject_scope_memories` to the module's imports/exports as needed.
