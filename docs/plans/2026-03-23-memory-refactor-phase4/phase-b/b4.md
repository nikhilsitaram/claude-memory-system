# B4: Register UserPromptSubmit hook in install.py

**Avoid:** Do not use a long timeout for the UserPromptSubmit hook -- it fires on every prompt and must be fast. Set timeout to 2 seconds (the script itself targets <800ms but network/disk latency may add overhead). Do not remove existing hooks in `merge_hooks` -- add UserPromptSubmit alongside the existing PreToolUse, SessionStart, and SessionEnd hooks. Do not make prompt_recall a required dependency for install -- if the script is missing, the hook will simply fail silently.

## Steps

### Step 1: Write failing tests for hook registration

In `tests/test_install.py`, add:

```python
class TestPromptRecallHook:
    def test_user_prompt_submit_hook_registered(self, tmp_path):
        """install.py registers a UserPromptSubmit hook for prompt_recall.py."""
        from unittest.mock import patch
        import json

        settings_file = tmp_path / "settings.json"
        settings_file.write_text("{}")

        with patch("install.get_settings_file", return_value=settings_file), \
             patch("install.Path.home", return_value=tmp_path):
            from install import merge_hooks
            settings = merge_hooks({}, "python3")

        assert "UserPromptSubmit" in settings.get("hooks", {}), "UserPromptSubmit hook not registered"
        hook_entries = settings["hooks"]["UserPromptSubmit"]
        assert any("prompt_recall" in str(e) for e in hook_entries), "prompt_recall.py not in hook command"

    def test_user_prompt_submit_hook_has_timeout(self, tmp_path):
        """UserPromptSubmit hook has a 2-second timeout."""

            from install import merge_hooks
            settings = merge_hooks({}, "python3")

        for entry in settings["hooks"].get("UserPromptSubmit", []):
            for hook in entry.get("hooks", []):
                if "prompt_recall" in hook.get("command", ""):
                    assert hook.get("timeout", 0) <= 3, "Timeout should be <= 3 seconds"
```

### Step 2: Add UserPromptSubmit hook to merge_hooks

In `install.py`, add to the `hooks_to_add` dict in `merge_hooks()`:

```python
"UserPromptSubmit": [
    {
        "matcher": "",
        "hooks": [
            {
                "type": "command",
                "command": f"{python_cmd} {scripts_dir}/prompt_recall.py",
                "timeout": 2,
            }
        ],
    }
],
```

### Step 3: Add prompt_recall.py to link_scripts

In `install.py`, find the `link_scripts()` function and add `"prompt_recall.py"` to the list of scripts to symlink.
