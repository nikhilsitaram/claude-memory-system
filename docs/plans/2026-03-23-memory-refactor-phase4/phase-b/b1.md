# B1: Add epistemic metadata columns (certainty, validity_context) with migration

**Avoid:** Do not use SQLite `ALTER TABLE ... ADD COLUMN IF NOT EXISTS` -- SQLite does not support that syntax. Instead, check `PRAGMA table_info(data_points)` for the column's existence before running ALTER TABLE. Do not set a default certainty value for existing rows during migration -- leave them as NULL (the scoring formula handles NULL by treating it as neutral). Do not add certainty as a NOT NULL column -- existing data_points must remain valid without it.

## Steps

### Step 3: Add migration function for epistemic columns

Add to `scripts/storage.py`:

```python
def _ensure_epistemic_columns(conn) -> None:
    """Add certainty and validity_context columns if they don't exist.

    Uses PRAGMA table_info to check before ALTER TABLE (SQLite has no
    ADD COLUMN IF NOT EXISTS).
    """
    existing = {row[1] for row in conn.execute("PRAGMA table_info(data_points)").fetchall()}
    if "certainty" not in existing:
        conn.execute("ALTER TABLE data_points ADD COLUMN certainty INTEGER DEFAULT NULL")
    if "validity_context" not in existing:
        conn.execute("ALTER TABLE data_points ADD COLUMN validity_context TEXT DEFAULT NULL")
    conn.commit()
```
