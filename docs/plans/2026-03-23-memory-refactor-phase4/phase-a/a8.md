# A8: Implement secret sanitization

**Avoid:** Do not use a deny-list approach that tries to enumerate every possible secret format -- use regex patterns for the most common categories (AWS, API keys, connection strings, JWTs, private keys, generic secret assignments). Do not make sanitization a separate processing step that reads/writes files -- it is a pure function `sanitize_secrets(text) -> text` called inline at write and inject points. Do not redact partial matches that might be false positives for short strings -- only match patterns with sufficient specificity (minimum 8 chars for generic secrets). Do not log the actual secret content -- only log that a redaction occurred and the type.

### Step 2: Implement sanitize_secrets in memory_utils.py

```python
import re as _re

# Secret detection patterns
_SECRET_PATTERNS = [
    (_re.compile(r"AKIA[0-9A-Z]{16}"), "[REDACTED:aws_key]"),
    (_re.compile(r"sk-[a-zA-Z0-9_-]{20,}"), "[REDACTED:api_key]"),
    (_re.compile(r"sk_live_[a-zA-Z0-9]{20,}"), "[REDACTED:api_key]"),
    (_re.compile(r"sk_test_[a-zA-Z0-9]{20,}"), "[REDACTED:api_key]"),
    (_re.compile(r"(postgres|mysql|mongodb)://[^\s]+"), "[REDACTED:connection_string]"),
    (_re.compile(r"eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}"), "[REDACTED:jwt]"),
    (_re.compile(r"-----BEGIN (RSA|EC|DSA|OPENSSH) PRIVATE KEY-----"), "[REDACTED:private_key]"),
    (_re.compile(r"(token|password|secret|apikey)\s*[=:]\s*['\"][^\s'\"]{8,}['\"]", _re.IGNORECASE), "[REDACTED:secret_assignment]"),
]


def sanitize_secrets(text: str) -> str:
    """Detect and redact common secret patterns from text.

    Replaces matches with [REDACTED:<type>] markers. Logs redactions to stderr.

    Args:
        text: Input text that may contain secrets.

    Returns:
        Text with secrets replaced by redaction markers.
    """
    if not text:
        return text
    result = text
    for pattern, replacement in _SECRET_PATTERNS:
        matches = pattern.findall(result)
        if matches:
            result = pattern.sub(replacement, result)
            print(f"Sanitized {len(matches)} {replacement} pattern(s)", file=sys.stderr)
    return result
```

Add `sanitize_secrets` to `__all__`.
