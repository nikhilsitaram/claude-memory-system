# A7: Add FTS5 sync to write and delete paths

**Avoid:** Do not add FTS5 sync to the SessionStart loading path (read-only, no writes). Do not add FTS5 sync to `_batch_update_data_point_access` (access tracking only updates salience/counts, not content). Do not wrap fts_insert/fts_delete calls in try/except that silently swallows errors -- FTS5 desync is a data integrity issue that should be logged. The sync points are exactly: write_memory (MCP), _apply_add_v3 (synthesis ADD), _apply_update_v3 (synthesis UPDATE), and soft_delete_data_point (storage).

### Step 4: Add FTS5 sync to storage.py soft_delete_data_point

In `scripts/storage.py`, extend `soft_delete_data_point`:

```python
def soft_delete_data_point(conn: sqlite3.Connection, dp_id: str) -> int:
    """Soft-delete a data_point by setting salience to 0.0 and removing from FTS5."""
    cursor = conn.execute(
        "UPDATE data_points SET salience = 0.0 WHERE id = ?", (dp_id,)
    )
    # Sync FTS5 index
    try:
        fts_delete(conn, dp_id)
    except Exception as e:
        import sys
        print(f"Warning: FTS5 delete failed for {dp_id}: {e}", file=sys.stderr)
    return cursor.rowcount
```
