# B1: Switch list_recent_sessions and get_recent_days to working days

**Avoid:** Don't remove `DEFAULT_RECENCY_WINDOW_DAYS` entirely — keep it assigned for backward compatibility but don't use it as a sentinel for mode detection (existing tests pass `max_age_days=7` explicitly, and `7 == DEFAULT_RECENCY_WINDOW_DAYS` would silently switch them to working-day mode). Instead, use a private `_USE_WORKING_DAYS = object()` sentinel as the default parameter. Don't change `list_all_sessions()` — it remains the low-level discovery function with no age filtering. Don't change `extract_transcripts_incremental()` — it already calls `list_recent_sessions()` and will automatically benefit from the working-day change.

### Step 2: Modify list_recent_sessions for working-day mode

In `scripts/indexing.py`, modify `list_recent_sessions()` (~line 229):

```python
from memory_utils import get_global_working_days, load_settings

# Private sentinel — distinct from any integer, so callers passing explicit
# max_age_days=7 get calendar-day behavior, not working-day behavior.
_USE_WORKING_DAYS = object()

def list_recent_sessions(
    max_age_days: int | None | object = _USE_WORKING_DAYS,
    min_file_size: int = MIN_SESSION_SIZE_BYTES,
    exclude_session_id: str | None = None,
    verify_content: bool = False,
) -> list[SessionInfo]:
    """List recent sessions, filtered by working days or calendar days.

    Args:
        max_age_days: _USE_WORKING_DAYS (default) uses working-day mode.
                      None = no age filter (backfill mode).
                      int = calendar-day cutoff (--days N mode).
        min_file_size: Minimum file size filter.
        exclude_session_id: Session ID to exclude.
        verify_content: If True, verify at least one assistant message.
    """
    all_sessions = list_all_sessions()

    if max_age_days is None:
        # Backfill mode: no age filter
        filtered = all_sessions
    elif max_age_days is _USE_WORKING_DAYS:
        # Default mode: use working days from settings
        settings = load_settings()
        n_days = settings.get("synthesis", {}).get("recentWorkingDays", 7)
        active_dates = get_global_working_days(n_days)
        if active_dates:
            active_set = set(active_dates)
            filtered = [
                s for s in all_sessions
                if get_session_date(s) in active_set
            ]
        else:
            # Fallback: calendar days if no working days found
            cutoff = datetime.now(timezone.utc) - timedelta(days=DEFAULT_RECENCY_WINDOW_DAYS)
            filtered = [s for s in all_sessions if s.file_mtime >= cutoff]
    else:
        # Explicit calendar-day cutoff (--days N backfill mode)
        cutoff = datetime.now(timezone.utc) - timedelta(days=max_age_days)
        filtered = [s for s in all_sessions if s.file_mtime >= cutoff]

    # Apply remaining filters
    filtered = [s for s in filtered if s.file_size >= min_file_size]
    if exclude_session_id:
        filtered = [s for s in filtered if s.session_id != exclude_session_id]
    if verify_content:
        filtered = [s for s in filtered if has_assistant_message(s.transcript_path)]

    return filtered
```

**Key decision:** Use a private `_USE_WORKING_DAYS = object()` sentinel instead of checking `== DEFAULT_RECENCY_WINDOW_DAYS`. This ensures callers passing `max_age_days=7` explicitly get calendar-day behavior (not working-day), while the default still uses working days. Identity check (`is`) distinguishes the sentinel from any integer.

### Step 3: Update get_recent_days to accept max_age_days

In `scripts/transcript_ops.py`, modify `get_recent_days()` (~line 376):

```python
def get_recent_days(
    exclude_session_id: str | None = None,
    max_age_days: int | None | object = None,
) -> list[str]:
    """List all days that have recent transcripts.

    Args:
        exclude_session_id: Optional session ID to exclude
        max_age_days: None uses working-day default (via _USE_WORKING_DAYS sentinel).
                      Pass an int for explicit calendar-day cutoff.
    """
    from indexing import _USE_WORKING_DAYS

    # None means "use default working-day mode" from the caller's perspective
    effective_age = _USE_WORKING_DAYS if max_age_days is None else max_age_days

    recent = list_recent_sessions(
        max_age_days=effective_age,
        exclude_session_id=exclude_session_id,
        verify_content=True,
    )
    days = set()
    for session in recent:
        days.add(get_session_date(session))
    return sorted(days)
```

Note: `get_recent_days(max_age_days=None)` means "use working-day default" (the common case). To get unlimited/backfill mode, callers must pass through `list_recent_sessions(max_age_days=None)` directly — backfill bypasses `get_recent_days` entirely per the design doc.
