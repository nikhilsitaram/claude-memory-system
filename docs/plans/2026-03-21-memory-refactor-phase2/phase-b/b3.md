# B3: Implement associative reinforcement for graph neighbors

**Avoid:** Do not traverse more than one hop in the graph -- the design specifies direct neighbors only (edges table). Deep traversal would be expensive and the diminishing returns formula already handles propagation over repeated accesses. Do not boost neighbors of neighbors in a single pass. Do not create new edges -- this only reinforces existing salience on linked nodes.

### Step 2: Implement query_neighbor_nodes in storage.py

Add to `scripts/storage.py`:

```python
@dataclass
class NeighborInfo:
    """A neighbor node with the connecting edge weight."""
    node_id: str
    salience: float
    edge_weight: float


def query_neighbor_nodes(
    conn: sqlite3.Connection, node_id: str
) -> list[NeighborInfo]:
    """Query direct graph neighbors of a node via valid edges.

    Looks up both directions (node as source or target).
    Excludes expired edges (valid_to IS NOT NULL).

    Returns:
        List of NeighborInfo with node_id, current salience, and edge weight.
    """
    rows = conn.execute(
        """
        SELECT n.id, n.salience, e.weight
        FROM edges e
        JOIN nodes n ON n.id = CASE WHEN e.source = ? THEN e.target ELSE e.source END
        WHERE (e.source = ? OR e.target = ?)
          AND e.valid_to IS NULL
        """,
        (node_id, node_id, node_id),
    ).fetchall()
    return [NeighborInfo(node_id=r[0], salience=r[1], edge_weight=r[2]) for r in rows]
```

    ).fetchone()

    accessed_salience = row[0] or 1.0
