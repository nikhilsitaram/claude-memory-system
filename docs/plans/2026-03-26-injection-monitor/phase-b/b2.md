# B2: Integrate injection logging into prompt_recall.py

**Avoid:** Do not change the stdout output format. The `[memory] Related context:` block is consumed by Claude Code. Injection logging is a fire-and-forget side effect only.

**Avoid:** Do not restructure the `main()` search/filter loop. The changes are additive: track filtered candidates in a new list, then call `log_prompt_recall` after the loop.

**Avoid:** Do not import injection_log at module level. Import inside the try block in `main()` to keep the fire-and-forget guarantee -- if injection_log is missing, prompt_recall still works.

### Step 2: Modify main() in prompt_recall.py to track filtered candidates

In `scripts/prompt_recall.py`, modify the `main()` function.

**Add a `filtered` list** before the search loop. Change the loop to track deduped items. Add `log_prompt_recall` call after the loop.

Replace the block from `memories = []` (line 137) through `print(f"Warning: prompt_recall took {elapsed:.2f}s (target <0.8s)", file=sys.stderr)` (line 164) with:

```python
        memories = []
        injected_log = []  # For injection log: {id, content_preview, scope}
        filtered_log = []  # For injection log: {id, content_preview, reason}
        for r in results:
            dp = r.data_point
            if is_recently_injected(dp.id, state_file, current_prompt_index=prompt_index):
                filtered_log.append({
                    "id": dp.id,
                    "content_preview": (dp.content or "")[:80],
                    "reason": "deduped",
                })
                continue
            memories.append({
                "content": dp.content,
                "certainty": getattr(dp, "certainty", None),
                "scope": dp.scope,
            })
            injected_log.append({
                "id": dp.id,
                "content_preview": (dp.content or "")[:80],
                "scope": dp.scope,
            })
            record_injection(dp.id, state_file, prompt_index)
            if len(memories) >= MAX_INJECTIONS:
                break

        output = format_injection(memories)
        if output:
            output = sanitize_secrets(output)
            print(output)

    except Exception as e:
        print(f"Warning: prompt_recall failed: {e}", file=sys.stderr)
    finally:
        if conn:
            close_db(conn)

    elapsed = time.monotonic() - start

    # Log to injection monitor (fire-and-forget)
    try:
        from injection_log import log_prompt_recall
        log_prompt_recall(
            session_id=session_id,
            prompt_preview=prompt[:80],
            candidates=len(results) if 'results' in locals() else 0,
            injected=injected_log if 'injected_log' in locals() else [],
            filtered=filtered_log if 'filtered_log' in locals() else [],
            latency_ms=elapsed * 1000,
        )
    except Exception:
        pass

    if elapsed > 0.8:
        print(f"Warning: prompt_recall took {elapsed:.2f}s (target <0.8s)", file=sys.stderr)
```
