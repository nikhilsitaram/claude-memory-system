# B1: Integrate injection logging into load_memory.py

**Avoid:** Do not change the stdout output format. The `<memory>...</memory>` block printed to stdout is consumed by Claude Code and must remain identical. The injection log is a side-effect, not part of the output.

**Avoid:** Do not change `_load_from_db`'s internal SQL queries or tier logic. The only change to `_load_from_db` is collecting metadata alongside the existing `sections` list, and returning a tuple instead of a plain string.

**Avoid:** Do not break the `_load_from_db` return of `None` (signals legacy v2 DB). The function returns `None` for v2 DBs, `""` for empty v3 DBs, or the tuple `(formatted_text, tiers_metadata)` for populated v3 DBs. Callers that check `is None` or `is not None` must still work correctly -- use a wrapper or careful typing.

**Avoid:** Do not use `sys.stdin.read()` -- the existing code uses `json.load(sys.stdin)` which reads and parses the entire stream. Capture the parsed result instead of discarding it.
