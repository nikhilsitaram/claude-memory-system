# A2: Register injection_log.py in install.py

**Avoid:** Do not modify `merge_hooks()` or add any new hooks -- the injection logging is called from within the existing hook scripts (load_memory.py and prompt_recall.py), not as a separate hook.

**Avoid:** Do not add injection_log.py to the `hooks_to_link` list -- it is a script, not a hook. It goes in `scripts_to_link` inside `link_scripts()`.

## Steps

### Step 1: Write failing test in tests/test_install.py

Add a new test class at the end of `tests/test_install.py`:

```python
class TestInjectionLogRegistration:
    """Verify injection_log.py is in the scripts_to_link list."""

    def test_injection_log_in_scripts_to_link(self):
        """injection_log.py must be registered for symlinking."""
        import inspect
        from install import link_scripts
        source = inspect.getsource(link_scripts)
        assert "injection_log.py" in source, (
            "injection_log.py not found in link_scripts(). "
            "Add it to the scripts_to_link list."
        )
```

Run: `python3 -m pytest tests/test_install.py::TestInjectionLogRegistration -v` -- expect 1 failure.

### Step 2: Add injection_log.py to scripts_to_link in install.py

In `scripts/install.py`, inside the `link_scripts()` function, add `"injection_log.py"` to the `scripts_to_link` list. Insert it after `"web_app.py"` (line 159) to keep it near related monitoring scripts:

Find this line in the list:
```python
        "web_app.py",  # Web frontend for browsing and managing memory
```

Add after it:
```python
        "injection_log.py",  # Injection monitor logging for SessionStart/PromptRecall hooks
```

### Step 3: Run tests and verify

Run: `python3 -m pytest tests/test_install.py::TestInjectionLogRegistration -v` -- expect 1 pass.
Run: `python3 -m pytest tests/test_install.py -v` -- no regressions.
